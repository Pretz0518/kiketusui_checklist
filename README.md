# 気血水　体質チェック（Web）

「健康まつり　気血水チェックシート&グラフ（改2023.11.9）.pptx」の内容に合わせた、PC・スマホ対応のセルフチェックアプリです。**Node.js / npx は不要**です。

## 使い方

1. **`index.html` をダブルクリック**してブラウザで開く  
   （うまくいかないときは `start.bat` をダブルクリック → `http://localhost:8080/`）
2. 6体質のチェックシートで当てはまる項目にチェック
3. **結果を見る** → レーダーグラフ・点数・説明を表示

グラフ（Chart.js）は CDN のため、**インターネット接続**が必要です。

## PPTX との対応

| 項目 | 内容 |
|------|------|
| 体質 | 気虚・気滞・血虚・瘀血・陰虚・水滞（各10項目） |
| 分類 | 「足りていない」「巡りが悪い」 |
| グラフ | 体質バランスの**レーダーチャート**（気･血･水） |
| イベント表記 | ぎふ市民健康まつり／（一社）岐阜市薬剤師会 |

## 結果の判定ロジック

- チェック **0件** → 「あなたの身体と心は整っています」
- **最多**の体質を表示（同点ならすべて列挙）
- **5個以上**の体質は最多の後ろに追加列挙

## ファイル構成

- `index.html` / `css/style.css` / `js/data.js` / `js/app.js`
- `img/` — ヒーロー・体質アイコンなどの画像
- `start.bat` / `start.ps1` — 簡易ローカルサーバー
